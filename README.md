# Advanced Calculator - Vanilla JS

## 🧮 Scientific Calculator

**Pure Vanilla JS** calculator with **scientific operations** (power ^), **dual display**, **error handling**, and **responsive design**. No libraries!

**Live Demo**: [Open index.html](index.html)

### ✨ Features

- **📱 Dual Display** - Operation history + current result
- **🔢 Full Keyboard** - Numbers 0-9, decimal point
- **➗ All Operations** - +, -, ×, ÷, ^ (power), %
- **🧹 Smart Controls** - AC (clear all), DEL (backspace)
- **✅ Input Validation** - Prevents double operators/decimal
- **❌ Syntax Error** - Handles invalid expressions
- **🎨 Dark Theme** - Glassy metallic design
- **📐 Responsive** - Mobile + desktop optimized
- **⚡ Instant Calc** - Real-time evaluation

### 🚀 Quick Start

```
Just open index.html - works offline!
```

**Example calculations**:
```
12 + 34 = 46
25 × 4 = 100
2 ^ 8 = 256
100 / 3 = 33.333...
(5 + 3) × 2 = 16
```

### 🎮 Controls

| Button | Function |
|--------|----------|
| **AC** | Clear everything |
| **DEL** | Delete last character |
| **%** | Modulo/percent |
| **÷ × - +** | Operators |
| **^** | Power/exponent |
| **=** | Calculate |

**Smart Input**:
- No leading zeros
- No double operators (55++ → 55+)
- No double decimals (3.5. → 3.5)
- Auto-clear after =

### 🛠️ Tech Stack

- **Vanilla JS** (~100 LOC, event delegation)
- **CSS Grid** - Perfect 4x4 layout
- **CSS Custom Properties** - Theme-ready
- **No dependencies**
